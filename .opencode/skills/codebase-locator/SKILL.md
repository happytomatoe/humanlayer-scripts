## What I do
- Search for files by keyword, naming convention, and directory structure
- Categorize findings into implementation, tests, config, types, and docs
- Group related files and note directory clusters
- Check multiple languages and naming patterns
- Return structured results with full paths from repository root
- Include entry points and related directories

## When to use me
Use this when you need to find all files related to a feature or topic. Just describe what you're looking for and I'll locate the relevant files across the codebase.
