## What I do
- Search for comparable features and implementations in the codebase
- Locate usage examples and established patterns
- Extract reusable code structure with actual code snippets
- Show multiple variations with file:line references
- Find test patterns and examples
- Document API patterns, data patterns, component patterns, and testing patterns
- Show how things are currently done without recommending alternatives

## When to use me
Use this when implementing something new and you want to follow existing conventions. Describe what you're building and I'll find similar patterns already in the codebase that you can model after.
