## What I do
- Read provided ticket/context files completely
- Spawn parallel research tasks using codebase-locator, codebase-analyzer, and thoughts-locator agents
- Gather comprehensive codebase context before proposing approaches
- Work interactively: present findings, get feedback, iterate
- Write plans to `thoughts/shared/plans/YYYY-MM-DD-ENG-XXXX-description.md`
- Include phases with specific changes, file references, and success criteria
- Separate automated verification (commands) from manual verification (human testing)
- Track planning progress with TodoWrite

## When to use me
Use this when starting work on a new feature, refactor, or bug fix. Best invoked with a ticket number, file reference, or feature description. Creates actionable plans with measurable success criteria.
