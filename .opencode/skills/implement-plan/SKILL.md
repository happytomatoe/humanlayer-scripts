## What I do
- Read the plan completely, including referenced tickets and files
- Follow phased implementation with automated verification after each phase
- Run success criteria checks (build, test, lint, typecheck)
- Update checkboxes in the plan file as work progresses
- Pause for human verification between phases (manual testing)
- Handle plan mismatches by stopping and communicating clearly
- Resume from existing checkmarks if work was partially completed

## When to use me
Use this when you have an approved plan in `thoughts/shared/plans/` and want it executed. Provide the plan path and the agent will implement phase-by-phase with verification after each step.
