## What I do
- Read documents with purpose, identifying their main goal and context
- Extract key decisions, trade-offs, constraints, and lessons learned
- Filter out exploratory rambling, rejected options, and superseded information
- Validate relevance and question if information is still applicable
- Return only actionable insights with technical specifications
- Note open questions and deferred decisions
- Distinguish decisions from explorations

## When to use me
Use this when you need to extract the signal from noise in a lengthy thoughts/ document. Instead of reading everything, I'll return only the high-value decisions and insights that matter.
