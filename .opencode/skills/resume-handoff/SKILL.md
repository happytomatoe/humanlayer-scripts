## What I do
- Read the handoff document completely, including linked research/plan documents
- Spawn focused research tasks to verify current state matches handoff
- Read learnings, recent changes, and artifacts from the handoff
- Present comprehensive analysis of original tasks, key learnings, and current state
- Create TodoWrite action plan based on handoff next steps
- Handle scenarios: clean continuation, diverged codebase, incomplete work, stale handoff
- Support ticket number lookup (finds most recent handoff for ENG-XXXX)
- Validate all file references still exist before proceeding

## When to use me
Use this at the start of a session to pick up where a previous session left off. Provide the handoff path or ticket number, and the agent will analyze context and propose next steps.
