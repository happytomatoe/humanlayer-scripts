## What I do
- Compact and summarize session context into a handoff document
- Write to `thoughts/shared/handoffs/ENG-XXXX/YYYY-MM-DD_HH-MM-SS_description.md`
- Include YAML frontmatter with date, researcher, git commit, branch, repository
- Document task statuses, critical references, recent changes, and learnings
- List artifacts, action items, and next steps
- Provide a `/resume_handoff` command for the next session

## When to use me
Use this at the end of a work session to hand off context to another agent or future session. Ensures continuity by capturing task status, code changes, learnings, and next steps.
